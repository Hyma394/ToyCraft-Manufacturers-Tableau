# ToyCraft Manufacturers - Tableau

## 📊 Project Overview

This project analyzes US toy manufacturers data from 2005 to 2016 using Tableau.

The project uses interactive visualizations and dashboards to understand manufacturer distribution, yearly trends, and state-wise patterns.

## 🎯 Objectives

- Analyze the number of toy manufacturers by year.
- Identify states with the highest number of toy manufacturers.
- Compare manufacturer distribution across different states.
- Visualize trends using Tableau dashboards.
- Present insights through interactive charts and visualizations.

## 🛠️ Tools & Technologies

- Tableau Public
- Microsoft Excel
- CSV Dataset
- Data Visualization

## 📁 Project Files

- `ToyCraft Manufacturers.twbx` – Tableau workbook
- `Week 39 - US Toy Manufacturers - 2005 to 2016.csv` – Dataset
- `Screenshots Of Dashboard And Stories.pdf` – Dashboard and story screenshots

## 📈 Dashboard

The Tableau dashboard includes:

- Number of Manufacturers by Year
- Number of Manufacturers by Index
- Analysis of Toy Manufacturers
- Number of Manufacturers from Each State
- Top 10 States with Most Toy Manufacturers
- Manufacturers from Each State
